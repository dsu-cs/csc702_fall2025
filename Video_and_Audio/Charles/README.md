This project implements and trains a U-Net convolutional neural network for image denoising. The goal is to remove noise (Gaussian) and blur (Average Pooling) from the  image.
First load  the dataset from kaggel and create a REDDenoiseDataset, generate noisy and blurred image pairs from a clean high-resolution dataset. This custom dataset feeds a U-Net architecture, composed of DoubleConv blocks that efficiently extract features, coupled with a symmetric encoder-decoder structure with skip connections to preserve crucial spatial details. hyperparameter tuning to explore the various configurations and find the optimal learning rate, batch size, and network dimensions that best mitigate the introduced degradations. The best-performing configuration was then utilized to train the final U-Net model over an extended period.
The outcome is a capable image denoising model, thoroughly evaluated using standard metrics such as Peak Signal-to-Noise Ratio (PSNR) and Structural Similarity Index Measure (SSIM). Visualizations and generated comparison videos distinctly the model's ability in transforming noisy inputs into cleaner outputs.
