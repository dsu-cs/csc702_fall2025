Within this file is a document that makes use of RAG to embed and chunk different dnd rule books. The model used as an llm is gpt-neo-125 for the fact that is is a small llm that works well on cpus since during creation of this project there were no gpus available. Due to the size of gpt-neo-125 the chunks had to stay lower in size and the repeat punishment value inside of the RAG model had to be set higher. In addition to reading from eight different dnd rule boosk, it was also implemented for the use of urls to be read so that special context could be added and scraped for things such as homebrew classes, races, items, monsters, etc... overall the size of this model affects how effective the output it but it shows a surprising amount of accuracy as well. There is the caveate of continuous repeats of information from the output but that is to be expected from these smaller LLM models.
