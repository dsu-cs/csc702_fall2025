## Image Generation Groupwork Project: Editing Random Noise Input Image
For our image generation project, we decided to see what would happen if we edit a precentage of the pixels of the input image before it is sent to a diffusion model. We used a pretrained stable diffusion model for image generation, the model came from Hugging Face's diffuser library. We used Google Colab to implement our code so we did not have to deal with any issues with installing libraries and dependencies. After we tested the pipeline to the diffusion model worked, we created a complete image of random noise. We then set up a loop to cycle through percentages from 0.0 to 1.0 with steps of 0.1, at each step we converted that percentage of random pixels to black and called the pipeline with edited noise as the initial input image. For the image generation at each step, the same prompt of "An image of a cat wearing a top hat" was used.

The results from our experiment can be seen in the output of the last cell of the notebook. The input image for each trial was displayed first, then the output image from the diffusion model is shown below that. The output images showed some interesting results as there were noticable changes as you go down the output of the cell. As more pixels were turned to black, it appears that the images become less realistic. The first couple cat images looked passable as real images, but after that most of them looked very cartoonish or abstract. It does also appear that the further you go down, the output showed more black and was darker compared to the first few images. Although there does appear to be some noticable differences between the images, it could be just random chance that they occured.
