# Hybrid Sequential Transformer for Sentiment Analysis
For this project we developed a Hybrid Transformer architecture that combines custom built Mini Transformer with the pre-trained BERT model to classify movie reviews from the IMDB dataset. For the Mini-Transformer encoder instead of just calling pre-built library functions, we decided to implement it from scratch in PyTorch, including the dot-product self-attention mechanism. This allowed us to really understand how attentional layers work. The output from our custom encoder was fed into BERT, which basically created this sequential learning process. This hybrid setup gave us the flexibility to experiment with different configurations like freezing BERT weights to speeding up training or fine-tuning the whole system to see how custom attention layers interact with a large language model. 

We designed the project in a modular manner, which cover everything from data tokenization to the final evaluation of the model. Also during training, we tuned parameters such as learning rate and epochs to optimize performance and achieved roughly 87% in the test set. One of the most useful parts of the entire project is the attention visualization; using Matplotlib and Seaborn, heatmaps that show precisely which words the model pays attention to while deciding if a review is positive or negative can be generated. The final pipeline automatically saves the trained model weights and its vocabulary for easy reload and testing of predictions.
